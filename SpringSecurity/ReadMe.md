

## Spring Security 
** Customize user and password for SpringSecurity

	- when we add Spring dependency in pom.xml that we have done just before, 
	then by default user is created by Spring Security which has username as user and password is random generated by console
	
	- Now we can log in using username and password but now we wan't to customize that username and password 
	for that in Spring boot there one class SpringSecuriy which is annotated by @ConfigurationProperties("spring.security")
	in this class there are user class which has properties user and password properties which we are going to override in application.properties file 
	to create our own user.
	
	** application.properties **
	- spring.security.user.name= john
	- spring.security.user.password= john123
